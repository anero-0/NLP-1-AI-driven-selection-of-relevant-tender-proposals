# ИИ-отбор релевантных тендеров (Контур.Закупки)

Веб-приложение для автоматического скоринга и отбора интересных тендеров из ежедневных Excel-выгрузок сервиса «Контур.Закупки».

Вместо того чтобы вручную просматривать сотни строк, пользователь просто загружает файл выгрузки на сайт. Система автоматически парсит данные (включая скрытые гиперссылки), прогоняет их через ML-модель (Случайный лес) и выдает удобную таблицу, отсортированную по привлекательности тендера, с возможностью скачать отформатированный результат.

## Особенности
* **Drag-and-Drop интерфейс**: Удобная загрузка `.xlsx` файлов через браузер.
* **Умный парсер**: Извлечение настоящих гиперссылок (на карточку тендера и электронную площадку), которые скрыты в ячейках «Контура» и теряются при обычном чтении.
* **Интеграция ML пайплайна**: 
  1. Выгрузка проходит предобработку с помощью встроенного скрипта `features.py` (чистка текста, извлечение дней до дедлайна, признаков наличия цены и региона).
  2. Подготовленные данные скармливаются модели классификации `RandomForestClassifier` (`pipeline.joblib`), которая была обучена на исторической разметке Марии.
  3. ИИ выдаёт вероятность (от 0 до 1), которая масштабируется с учётом порога отсечения (`threshold.joblib`) и переводится в **целочисленный балл от 0 до 100**.
* **Что означают баллы (0-100)**: 
  Балл — это уверенность ИИ в том, что данный тендер релевантен. 
  - `70-100` (зелёный цвет): ИИ крайне рекомендует тендер к участию (вероятность сильно выше порога).
  - `40-69` (жёлтый цвет): Пограничные случаи, стоит посмотреть глазами.
  - `0-39` (красный цвет): Нерелевантный тендер, скорее всего мусор.
* **Красивый экспорт**: Скачивание результатов обратно в `.xlsx` с сохранением гиперссылок, закрепленной шапкой и цветовым кодированием в зависимости от балла.

## Технологический стек
* **Backend**: FastAPI, Uvicorn
* **Обработка данных**: pandas, openpyxl, scikit-learn
* **Frontend**: HTML5, Vanilla CSS, JS + Jinja2 (на стороне сервера)

```text
NLP-1-AI-driven-selection-of-relevant-tender-proposals/
├── app/
│   ├── main.py            # Маршруты и управление сессиями (FastAPI)
```

## Установка и запуск

1. **Склонируйте репозиторий и перейдите в папку проекта:**
   ```bash
   git clone https://github.com/anero-0/NLP-1-AI-driven-selection-of-relevant-tender-proposals.git
   cd NLP-1-AI-driven-selection-of-relevant-tender-proposals
   ```

2. **Установите зависимости:**
   Для работы требуются `fastapi`, `uvicorn`, `openpyxl`, `pandas`, `scikit-learn` и др. Установить их можно командой:
   ```bash
   pip install -r requirements.txt
   ```

3. **Запустите сервер:**
   Запустите приложение через ASGI-сервер `uvicorn`:
   ```bash
   python -m uvicorn main:app --host 127.0.0.1 --port 8000
   ```
   *(Флаг `--reload` можно добавить для автоперезапуска сервера при изменении кода).*

4. **Откройте приложение:**
   Перейдите в браузере по адресу [http://localhost:8000](http://localhost:8000)

## Как пользоваться
1. На главной странице нажмите на область загрузки или перетащите в неё ваш файл `Контур.Закупки...xlsx`.
2. Дождитесь окончания парсинга и работы ML-модели.
3. На странице результатов ознакомьтесь со списком отсортированных тендеров (сверху самые релевантные). 
4. При необходимости отфильтруйте результаты по минимальному баллу с помощью ползунка.
5. Нажмите кнопку **«Скачать xlsx»**, чтобы получить итоговый Excel-документ для работы.
